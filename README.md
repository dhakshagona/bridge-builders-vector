# Bridge Builders Hackathon — Team Vector

Official repository for Team Vector at the 2026 Bridge Builders Hackathon.

## Challenge

Build something that makes life measurably easier for an immigrant family in America.

Focus on:
- one real person or family
- one clear problem
- one useful solution
- one working prototype

A small feature that works well is better than a large unfinished project.

## Build Flow

1. Brainstorm in Gemini
2. Plan and refine with ChatGPT or Claude
3. Build with Codex
4. Work in VS Code
5. Use Live Share for collaboration
6. Test the project
7. Push final code to GitHub
8. Deploy on Render
9. Test the public Render link
